
# Мэтчинг товаров

## Описание проекта

Целью проекта является разработка инструмента, позволяющего автоматически находить соответствия между товарами компании на основе их текстовых описаний. Такое решение актуально для задач анализа и расширения ассортимента.

Модель должна обеспечивать высокую точность при сопоставлении товаров и работать на реальных данных с высокой степенью "шума" — различиями в формате, регистре, длине и структуре названий.

## Используемый подход

Для решения задачи были реализованы следующие шаги:
- Очистка и нормализация данных, удаление дубликатов.
- Лемматизация и стемминг текстов наименований (с помощью Natasha и SnowballStemmer).
- Построение векторных представлений товаров с помощью CountVectorizer.
- Объединение признаков и кластеризация товаров (KMeans) для ограничения области поиска аналогов.
- Вычисление косинусного сходства для поиска наиболее похожих товаров внутри кластера.
- Оценка точности модели на размеченной тестовой выборке с помощью метрик `accuracy@1` и `accuracy@5`.

## Результаты

Модель показала следующие результаты на тестовых данных:

- **Accuracy@1**: 0.5343  
- **Accuracy@5**: 0.8878  
- **Accuracy@1 (точные совпадения)**: 0.6758  
- **Accuracy@1 (аналоги)**: 0.4524  

## Вывод

Разработанная модель показывает хороший уровень точности при сравнительно простой реализации. Её можно использовать для автоматического подбора аналогов и как основу для более сложных решений.


## Запуск

Минимальные зависимости указаны в `requirements.txt`. Основная логика оформлена в виде класса `Processor`:

```python
model = Processor(n_clusters=1000)
model.fit(self_prod['sku_name'])  # обучение на названиях
model.predict("Пример названия товара", top_k=5)  # прогноз
```
